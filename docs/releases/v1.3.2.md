# Tomorrow Drop 1.3.2

**Transferred. Used. Done.** This version publishes the changes of the tags `v1.3.0` and `v1.3.1`, which were tagged before the version was set and so were never built as a release. It has everything that is in [1.2.1](v1.2.1.md), and it is compatible with it: the protocol is still version 1, and devices paired before keep working.

## What is new

- **No more false error after sending several files.** On Android, iPhone and iPad the receiving device asks where to save each file. The sender waited only 30 seconds for the answer, so a transfer of several files showed an error on the sender although every file was saved. The sender now waits up to 5 minutes. A person who takes longer than that in the save pickers still makes the sender fail with a timeout.
- **The desktop window opens larger**: 80% of the free screen width and 95% of its height, never smaller than 420×640. Linux still opens at 420×640.
- **A shorter top on the home screen** (desktop and Android), so the device list gets the height. The logo is above the name and the slogan, all centred, on desktop and on phones. On desktop the address of this device is in the left corner and the fingerprint button in the right one, and a narrow window no longer squeezes the address under the button.
- **The title of every inner screen is centred in the whole window**, not in the room the back button leaves.
- **`make install-macos`** builds the application for the Mac in use and installs it in Applications (for people who build from source).

## Platforms tested

The automated suite passes (including the race detector) and the checks in `scripts/check.sh` pass. The macOS application was built and installed on an Apple silicon Mac, signed ad hoc. The Windows screen-size code is type-checked, not run on Windows. The Intel bundle was built, not run on Intel hardware. The iPhone and iPad app has its own screens and does not have the shorter home screen yet. The Android app was not built for this version.

## Known limits

- The limits of [1.2.1](v1.2.1.md) remain.
- On Linux the window opens at 420×640.
- The iPhone and iPad home screen keeps its previous header.
- Asking where to save before the files are sent would remove the 5 minute limit of the save pickers; it is not done.
