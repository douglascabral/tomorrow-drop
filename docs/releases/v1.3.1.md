# Tomorrow Drop 1.3.1

**Transferred. Used. Done.** This version centres the logo and the slogan on the home screen of the phone application. It has everything that is in [1.3.0](v1.3.0.md), and it is compatible with it: the protocol is still version 1, and devices paired before keep working.

**This version was tagged before `VERSION` was set to it, so the release process refused it and no files were published under it. Its changes are published in [1.3.2](v1.3.2.md); use that version.**

## What is new

- **The logo is above the name and the slogan, all centred, on phones** (Android), as it already was on desktop in 1.3.0. The address of this device stays on the line below, with the fingerprint button as an icon.

| `SHA256SUMS` | checksums of the files above |

See [v1.0.0](v1.0.0.md) for the install steps of the command-line programs. The Android app and the iPhone/iPad app are built from source (`make install-android`, `make install-ios`) and are not published to any store.

## Platforms tested

The automated suite passes (including the race detector). The Android app was not built for this version, so the phone layout was checked only by the automated screen tests, not on a device. The iPhone and iPad app has its own screens and is not changed.
