# Tomorrow Drop 1.0.0

**Transferred. Used. Done.** Send files, texts and links between devices on the same local network. No account, no cloud, no central server, and no history kept.

## What is in this release

| File | For |
|---|---|
| `TomorrowDrop-linux-amd64.deb` | Linux (Debian, Ubuntu and derivatives), graphical application |
| `TomorrowDrop-windows-amd64.exe` | Windows, graphical application (icon embedded) |
| `tdrop-linux-amd64` | Linux, command-line program |
| `tdrop-windows-amd64.exe` | Windows, command-line program |
| `tdrop-darwin-arm64` | macOS on Apple Silicon (M1, M2, M3 and later), command-line program |
| `tdrop-darwin-amd64` | macOS on Intel, command-line program |
| `SHA256SUMS` | Checksums of every file above |

The macOS graphical application, the Android app and the iPhone/iPad app are not part of this release's files: they are built from source (`make package-macos`, `make install-android`, `make install-ios`) and are not published to any store.

## Install

Linux:

```sh
sudo apt install ./TomorrowDrop-linux-amd64.deb
```

Command line (Linux):

```sh
chmod +x tdrop-linux-amd64
./tdrop-linux-amd64 help
```

Command line (macOS): choose the file for your Mac (`tdrop-darwin-arm64` on Apple Silicon, `tdrop-darwin-amd64` on Intel; `uname -m` prints `arm64` or `x86_64`), then:

```sh
chmod +x tdrop-darwin-arm64
./tdrop-darwin-arm64 help
```

The file is not signed or notarized, so macOS may block the first run. Allow it in System Settings > Privacy & Security, or remove the quarantine flag once you have checked the checksum: `xattr -d com.apple.quarantine ./tdrop-darwin-arm64`.

Windows: run `TomorrowDrop-windows-amd64.exe`. Windows SmartScreen shows a warning, because the file is not code-signed yet. Choose "More info" and then "Run anyway" only if you downloaded it from this release.

Check the download against `SHA256SUMS`:

```sh
sha256sum -c SHA256SUMS
```

## Requirements

- Both devices on the same local network. The app uses UDP port 47520 for discovery and TCP port 47521 for transfers; allow them in the firewall.
- Linux: the graphical libraries (OpenGL, X11) are installed with the `.deb`.
- Each person compares the fingerprints of both devices once, when pairing.

## Platforms tested

The owner tested the application on the devices in use and approved this version against the acceptance checklist in [docs/ACCEPTANCE.md](../ACCEPTANCE.md). The automated tests run on Linux, Windows and macOS in the CI. The graphical Linux and Windows applications were not yet run on a real Linux or Windows machine.

## Known limits

- Android and iOS save received files in the app storage and in the Files app, not in a system Downloads folder.
- The packages are not code-signed or notarized, so Windows and macOS show security warnings.
- Pairing is manual: the fingerprints must be compared on both devices.
- Interrupted transfers restart from the first byte. There is no resume.
- On iPhone and iPad, and on phones, the app must stay open. Leaving it interrupts running transfers.
